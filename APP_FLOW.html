YAML

.github/workflows/vibeguard.yml

GitHub Actions workflow configuration

name: VibeGuard Security Scan
on: [push, pull_request]

jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: vibeguard/scan-action@v1
        with:
          fail-on: critical
          output: sarif,pr-comment
          webhook: ${{ secrets.SLACK_WEBHOOK }}

1

Safe Auto-Fix

Deterministic fixes for known patterns. No LLM needed. E.g., moving secrets to .env, adding parameterized queries.

vibeguard fix
2

LLM-Assisted Fix

Complex issues get AI-powered fixes. Gathers context, sends to LLM, validates AST, presents patch.

vibeguard fix --ai
3

AST Validation

Every LLM-generated patch is validated against the AST parser before being presented. No broken code ships.

tree-sitter parse(patch)
4

Developer Review

All patches shown as diffs. Developer must approve before any file is written. No silent changes.

git diff --staged
5

Re-Scan Verify

After applying fix, automatic re-scan verifies no new issues introduced. Loop until clean.

vibeguard scan --verify
6

Suppression Registry

If developer chooses to suppress instead of fix, reason is recorded. Telemetry refines community rules.

# vibeguard:ignore VG-001

pub struct ScanResult {
    pub findings: Vec<Finding>,
    pub scan_metadata: ScanMetadata,
    pub summary: ScanSummary,       // total, score (0-100)

    pub id: String,                  // "VG-SECRET-001"

    pub severity: Severity,          // Critical | High | Medium | Low

    pub line: u32,

SQL

PostgreSQL Schema (Key Tables)

Core database tables for persistence

-- Organizations & Plans
CREATE TABLE organizations (
    id UUID PRIMARY KEY,
    name TEXT NOT NULL,
    plan TEXT DEFAULT 'free',
    settings JSONB
);

-- Scan History
CREATE TABLE scans (
    id UUID PRIMARY KEY,
    org_id UUID REFERENCES organizations(id),
    trigger TEXT,          -- 'cli' | 'ci' | 'ide' | 'hook'
    risk_score INT,        -- 0-100
    scan_duration_ms INT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Individual Findings
CREATE TABLE findings (
    id UUID PRIMARY KEY,
    scan_id UUID REFERENCES scans(id),
    rule_id TEXT,          -- "VG-SECRET-001"
    severity TEXT,
    file_path TEXT,
    line INT,
    suppressed BOOLEAN DEFAULT FALSE,
    suppression_reason TEXT
);

-- AI Trust Scores
CREATE TABLE ai_trust_scores (
    id UUID PRIMARY KEY,
